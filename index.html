С чего начинаем

Что уже умеем и куда идём

Первый модуль закончен: ты умеешь хранить данные и писать программы с меню. Но все они были написаны одним сплошным текстом, сверху вниз. Если одно и то же действие нужно в трёх местах, код приходилось повторять. Второй модуль учит собирать программу из частей. Первая и главная часть — функция.

Что уже умеем

  • условия и циклы;
  • списки, кортежи и словари;
  • распаковку: a, b = pair;

Что будем уметь через час

  • писать свои функции с параметрами;
  • возвращать результат через return;
  • не путать return и print;
  • записывать сигнатуру функции;
  • возвращать несколько значений и None;
  • разбивать задачу на маленькие функции.

На КР

Третья контрольная проверяет функции. Программу нужно собрать из функций, а перед каждой функцией записать её сигнатуру. В первой контрольной сигнатура стояла прямо в условии: dist: str str -> int. Сегодня ты научишься читать такие записи и писать по ним код.

1

Зачем нужна функция

Определение и вызов

Магазин считает цену со скидкой. Без функций формулу приходится писать заново для каждого товара.

Так писать плохо. Формула повторяется, и если в ней ошибка, исправлять придётся в каждом месте. Функция — это кусок программы, у которого есть имя. Его пишут один раз, а потом вызывают по имени столько раз, сколько нужно.

Разберём первые три строки. Это определение функции.

  • def — ключевое слово: «сейчас будет функция».
  • with_discount — имя функции. Правила те же, что для переменных: маленькие английские буквы и подчёркивание.
  • (price, percent) — параметры: имена для данных, которые функция получит при вызове.
  • Двоеточие и отступ — как у if и for. Всё, что с отступом, — тело функции.
  • return final — функция отдаёт результат и на этом заканчивается.

Строка with_discount(1200, 15) — это вызов функции. Значения в скобках называются аргументами. Аргументы попадают в параметры по порядку: 1200 — в price, 15 — в percent. Лектор называет параметры в определении формальными, а значения при вызове — фактическими параметрами. Это те же два понятия.

Функции ты вызываешь с первой лекции. Просто раньше их писали другие люди.

Ловушка

Определение само ничего не делает. Python читает строки def и запоминает функцию, но её тело не выполняет. Тело выполняется только при вызове. Поэтому функцию нужно определить раньше, чем выполнится её вызов.

Python дошёл до первой строки и не нашёл имени double: определение стоит ниже и ещё не прочитано. Отсюда правило: сначала в файле идут все функции, потом — основная программа, которая их вызывает.

2

return — не print

Вернуть значение или показать его

Это главная путаница темы. Вернёмся к кофемашине. return — это чашка кофе, которую машина выдала: её можно выпить, отнести другу, добавить в неё молоко. print — это фотография кофе на экране: посмотреть можно, выпить нельзя.

Сравним две функции. Они считают одно и то же, но поступают с результатом по-разному.

Проследи вывод. Вызов make_sum(2, 3) ничего не напечатал: он вернул число 5, и оно попало в переменную x. Вызов show_sum(2, 3) напечатал 5 сам, но программе ничего не отдал. В переменной y оказалось None.

Термин

None — особое значение, которое означает «ничего». Функция, в которой нет return, всегда возвращает None.

С None нельзя считать. Вот что получится, если результат «печатающей» функции попробовать использовать дальше.

Число 5 появилось на экране, а в выражение попало None. Сложить None и 10 нельзя: ошибка TypeError. Отсюда главное правило этой лекции.

Правило

Функция считает и возвращает. Печатает основная программа. Функция, которая возвращает результат, полезнее: результат можно напечатать, сохранить, сравнить или передать в другую функцию.

return заканчивает функцию

Как только выполнился return, функция закончена. Строки после него уже не выполняются. Поэтому в функции может быть несколько return — сработает только один. Первый пример — задание лектора со слайда: функция, которая считает модуль числа, то есть число без знака.

Слайд просит ещё и проверить функцию. Удобно сверить её с готовой abs: ответы совпали. Если число отрицательное, первый return сразу заканчивает функцию. Иначе до него дело не доходит, и срабатывает второй. Так же устроена функция с тремя вариантами ответа.

Здесь не нужны elif и else. Если число положительное, первый return сразу заканчивает функцию, и до остальных строк дело не доходит.

Функции-вопросы

Функция может возвращать True или False. Такие функции отвечают на вопрос «да или нет», и называют их соответственно: is_... («является ли») или has_... («есть ли»).

Сравнение само даёт True или False, поэтому его можно вернуть сразу, без if. Вызов такой функции ставят прямо в условие: if is_even(4):. Писать == True не нужно.

Параметры и аргументы

Что куда попадает при вызове

Аргументы раздаются параметрам по порядку: первый аргумент — первому параметру, второй — второму. Python не знает, что ты имел в виду. Он не проверяет смысл.

Вторая строка вывода бессмысленна, но ошибки нет: число 12 честно попало в параметр name. За порядком аргументов следит программист.

А вот количество Python проверяет. Аргументов должно быть ровно столько, сколько параметров.

Сообщение читается так: функции ticket не хватает одного обязательного аргумента — для параметра price.

Тренажёр 3

Какой аргумент куда попал

Функция ticket(name, seat, price) ждёт три значения. Собери вызов из кнопок: каждое нажатие добавляет аргумент. Попробуй перепутать порядок, дать меньше трёх значений и больше трёх.

Аргументом может быть любое выражение

При вызове Python сначала вычисляет каждый аргумент, а потом передаёт готовые значения. Поэтому аргументом может быть число, переменная, формула и даже вызов другой функции. Имена переменных в программе не обязаны совпадать с именами параметров.

Переменные функции живут только внутри неё

Параметры и переменные, созданные в теле функции, существуют только во время вызова. Когда функция закончилась, они исчезают. Снаружи их не видно — ты видел это в тренажёре 1.

Первый print сработал. Второй остановил программу: переменной final в основной программе нет. Она была «внутренней кухней» функции. Единственный выход для результата — return. Подробно о том, какие переменные где видны, расскажет следующая лекция.

Функция может спрашивать сама

Иногда повторяется не расчёт, а ввод. Тогда в функцию выносят вопрос. Текст вопроса удобно сделать параметром.

Функция ask_number задаёт вопрос, превращает ответ в число и возвращает его. Основной программе остаётся две коротких строки вместо четырёх.

Итог раздела

  • Аргументы попадают в параметры по порядку. Смысл Python не проверяет, количество — проверяет.
  • Аргумент сначала вычисляется, потом передаётся.
  • Переменные функции снаружи не видны. Результат выходит только через return.

Сигнатура

Сначала план функции, потом код

Сигнатура — это краткий паспорт функции: её имя, типы параметров и тип результата. Лектор требует сигнатуру перед каждой функцией. Её пишут комментарием: слева от стрелки — что функция получает, справа — что возвращает.

СигнатураКак читать
with_discount: float float -> floatПолучает два дробных числа, возвращает дробное число.
is_even: int -> boolПолучает целое число, возвращает True или False.
ticket: str int int -> strПолучает строку и два целых числа, возвращает строку.
count_upper: str -> intПолучает строку, возвращает целое число.
min_max: list -> tupleПолучает список, возвращает кортеж.
all_lunches: -> listНичего не получает, возвращает список.

Лектор пишет сигнатуру короче — прямо в строке def, после двоеточия: def count_upper(text): # str -> int. Для кортежей у него своя запись: f — дробное число, (f,f,f) — кортеж из трёх дробных чисел. Например, у функции, которая считает скалярное произведение двух векторов, сигнатура (f,f,f) (f,f,f) -> f. Годится любая из двух записей. Главное, чтобы сигнатура была.

Сигнатуру пишут до кода. Она заставляет ответить на три вопроса: как функция называется, что ей нужно на входе и что она отдаёт. Когда ответы есть, тело пишется гораздо легче. Под сигнатурой добавляют одну строку: что функция делает.

Внутри функции можно писать всё, что ты уже умеешь: циклы, условия, накопители. Метод isupper() отвечает, большая ли буква, а islower() — маленькая ли. Они устроены так же, как знакомый isdigit(). Накапливать в цикле можно и строку. Лектор на паре так переворачивал текст: каждую следующую букву ставил в начало новой строки — rev = symbol + rev.

В функции может работать и цикл while.

Обрати внимание на последнюю строку. Внутри функции параметр n уменьшался до двойки, а переменная number в программе осталась прежней. Функция получила значение в свой параметр и меняла только его.

Цифры числа можно перебрать и по-другому: превратить число в строку через str() и пройти по ней циклом for. Каждая цифра — это символ, а int() снова делает из него число. Так на паре считал лектор.

Ранний выход из цикла

Частая задача — проверить, есть ли в наборе хотя бы один нужный элемент. Раньше для этого нужны были флаг и break. В функции всё короче: нашли — сразу return True.

Ловушка

Строка return False стоит после цикла, а не внутри него. Ответить «нет» можно только тогда, когда проверены все элементы. Если написать else: return False внутри цикла, функция посмотрит только на первый элемент.

Тренажёр 4

Ранний выход: где стоит return False

Впиши целые числа через пробел и переключай два варианта функции. Жёлтые числа функция проверила, пунктирные — нет.

  1. def has_negative(numbers):
  2. for number in numbers:
  3. if number < 0:
  4. return True
  5. return False
  1. def has_negative(numbers):
  2. for number in numbers:
  3. if number < 0:
  4. return True
  5. else:
  6. return False

Тем же способом функция возвращает не «да или нет», а место, где элемент нашёлся. Если элемента нет, принято возвращать -1: такого индекса не бывает.

Это линейный поиск из третьей лекции, только теперь он — функция. Так в функцию превращается любой знакомый алгоритм. Данные, которые раньше лежали в переменных программы, приходят через параметры. А там, где раньше стоял print с ответом, теперь стоит return.

Итог раздела

  • Сигнатура: имя, типы параметров, стрелка, тип результата. Пишется комментарием перед функцией.
  • В теле функции работают циклы и условия, как в обычной программе.
  • Нашли нужное в цикле — return сразу. Ответ «не нашли» — только после цикла.
5

Несколько значений и None

Кортеж в ответ и ответ «ничего»

Функция возвращает одно значение. Но этим значением может быть кортеж или список — а в них помещается сколько угодно данных. Если после return написать значения через запятую, Python сам соберёт из них кортеж.

Принять такой ответ удобнее всего распаковкой: слева столько переменных, сколько значений вернула функция. Распаковку ты знаешь по теме о кортежах.

Кортеж слева и справа от знака =

Распаковка умеет ещё одну полезную вещь: менять значения нескольких переменных одной строкой. Python сначала вычисляет всё, что стоит справа от знака =, собирает из этого кортеж и только потом раздаёт значения переменным слева.

Когда присваиваний два, вторая строка видит уже изменённое значение. Одна строка с кортежем берёт старые значения обеих переменных. Это нужно, когда новое значение каждой переменной считается из старых. Пример — числа Фибоначчи: каждое следующее число равно сумме двух предыдущих.

Функция может вернуть и список, который она собрала сама. Заодно посмотри: одна функция здесь вызывает другую.

Когда считать нечего: None

Бывают данные, для которых ответа нет. Среднее пустого списка посчитать нельзя: придётся делить на ноль. В таком случае функция честно возвращает None — «ответа нет». А программа обязана проверить результат до того, как им пользоваться.

Проверка на None пишется словом is: if result is None:. Обратная проверка — if result is not None:. Проверка неверных данных стоит в самом начале функции: плохой случай отсекается сразу, а дальше идёт обычный расчёт.

Если функция возвращает кортеж, но иногда — None, порядок такой: сначала проверить, потом распаковать. Распаковать None нельзя.

Тот ли это кортеж: проверка аргумента

В задании лектора про смешанное произведение векторов сказано: если аргумент — не кортеж из трёх чисел, функция возвращает None. Значит, функция должна проверить тип аргумента, его длину и то, что внутри — числа. Тип значения возвращает функция type. Его сравнивают с названием типа: tuple, list, int, float, str.

ВыражениеРезультатПояснение
type((3.0, 4.0)) == tupleTrueЭто кортеж.
type([3.0, 4.0]) == tupleFalseСписок — не кортеж.
type(2) == intTrueЦелое число.
type("2") == intFalseСтрока, а не число.

Проверку выносят в отдельную функцию-вопрос. Вот она для точки на плоскости — кортежа из двух чисел. Лектор на паре написал такую же для векторов из трёх чисел и назвал её parameter_ok.

Порядок проверок важен. Сначала тип: у числа нет длины, и len(7) остановил бы программу. Потом длина: кортеж из трёх чисел нельзя распаковать в две переменные. И только потом — каждое значение: int или float. Строка (x1, y1) = p — распаковка. Лектор пишет её со скобками, но скобки можно и не писать.

Числа, которые ввёл пользователь, split() выдаёт списком. Функция tuple() превращает список в кортеж — его уже можно передать функции, которая ждёт кортеж.

Во второй раз введены три числа. Кортеж получился из трёх элементов, is_point его не пропустила, и distance вернула None. Программа проверила результат и сообщила об ошибке, а не упала.

На КР

В заданиях лектора встречается требование: «при неверных входных данных функция возвращает None». Это значит три вещи. В начале функции стоит проверка данных. В комментарии под сигнатурой сказано, когда возвращается None. Программа проверяет результат через is None.

Итог раздела

  • return a, b возвращает кортеж. Принимаем распаковкой: x, y = f().
  • a, b = b, a + b — обе переменные получают значения, посчитанные из старых.
  • None — ответ «результата нет». Проверка: is None.
  • Сначала проверяем на None, потом считаем или распаковываем.
  • Проверка аргумента: сначала тип (type(p) != tuple), потом длина, потом каждое значение.
6

Функция вызывает функцию

Большая задача из маленьких частей

Большую задачу трудно решить сразу. Её делят на маленькие, и каждую маленькую решает своя функция. Это называется декомпозиция. Пример: площадь треугольника по трём сторонам. По формуле Герона площадь равна корню из p * (p - a) * (p - b) * (p - c), где p — половина периметра. Но сначала нужно убедиться, что такой треугольник вообще существует.

Функция area сама почти ничего не считает. Она спрашивает у is_triangle, есть ли треугольник, берёт периметр у perimeter и подставляет его в формулу. Что даёт такое устройство:

  • Каждая часть простая. В функции три-пять строк, ошибиться трудно.
  • Каждую часть можно проверить отдельно. Вызвал is_triangle(1, 1, 5) — сразу видно, верно ли она работает.
  • Части можно использовать снова. Периметр пригодится и без площади.
  • Программа читается как текст. Имя функции говорит, что происходит.

Писать удобно сверху вниз. Сначала запиши основную программу так, будто нужные функции уже есть. Потом для каждой функции запиши сигнатуру. И только потом — тела. В файле функции всё равно стоят выше основной программы: иначе Python их не найдёт.

Ловушка

Скобки при вызове нужны всегда, даже если параметров нет. Запись all_lunches без скобок функцию не вызывает: это просто её имя. Вызов — all_lunches().

Итог раздела

  • Одна функция — одна маленькая задача.
  • Функции вызывают друг друга: результат одной становится аргументом другой.
  • Порядок работы: основная программа, сигнатуры, тела функций.

Практикум: бизнес-ланч

Собираем всё вместе

Пишем программу в виде задания с контрольной. Кафе предлагает бизнес-ланч: один суп, одно горячее и один напиток. Супы — борщ и солянка, горячее — паста и плов, напитки — чай и морс. У каждого блюда своя цена.

  • a) Функция price_of: str -> float возвращает цену блюда. Функция lunch_price: list -> float возвращает цену обеда из нескольких блюд.
  • b) Функция all_lunches: -> list возвращает все возможные обеды. Функция cheapest: list -> tuple возвращает самый дешёвый обед и его цену. Программа выводит все обеды с ценами и самый дешёвый обед.
  • c) В комментариях объяснить, какие функции вызывают другие функции и зачем задача так разбита.

Четыре наблюдения. Первое: функция price_of читает словарь prices, который создан в основной программе выше. Читать такие данные функция может. Менять их изнутри — отдельный разговор, он будет в следующей лекции. Второе: у all_lunches нет параметров, но скобки при определении и при вызове всё равно стоят. Третье: три вложенных цикла собирают все сочетания — это полный перебор: каждое сочетание ровно один раз. Результат не печатается, а складывается в список. Четвёртое: cheapest возвращает два значения, и программа принимает их распаковкой в две переменные.

На КР

Во второй задаче первой контрольной было то же устройство, только про города: функция dist: str str -> int возвращала расстояние между двумя городами, а программа перебирала все круговые маршруты и запоминала самый короткий в двух переменных. Теперь ты знаешь, как собрать такую программу из функций.

Тренажёр 5

Охота на баги

В каждой программе одна ошибка. Щёлкни по строке, которую нужно исправить.

Программа со слайда лектора: она должна вывести большее из двух чисел.

Traceback (most recent call last):
  File "max_val.py", line 7, in <module>
    print(maxVal(3, 8))
NameError: name 'maxVal' is not defined

Верно. Функция названа max_val, а вызвана maxVal. Имя при вызове должно совпадать с именем в определении до буквы. Эта опечатка есть на слайде лектора.

Программа должна удвоить число, прибавить единицу и вывести 9.

Traceback (most recent call last):
  File "double.py", line 5, in <module>
    result = double(4) + 1
TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'

Верно. Python остановился на строке 5, но причина — в строке 2. Функция печатает результат вместо того, чтобы вернуть его. Она возвращает None, а к None нельзя прибавить единицу. Нужно return x * 2.

Программа должна вывести площадь прямоугольника 5 на 3.

Traceback (most recent call last):
  File "area.py", line 5, in <module>
    print(area(5))
TypeError: area() missing 1 required positional argument: 'height'

Верно. У функции два параметра, а аргумент передан один. Python сообщает, что параметру height значения не досталось. Нужно area(5, 3).

Программа должна вывести квадрат числа 5.

Traceback (most recent call last):
  File "square.py", line 1, in <module>
    print(square(5))
NameError: name 'square' is not defined

Верно. Вызов стоит выше определения. Когда Python выполняет первую строку, функции square ещё не существует. Вызов нужно перенести в конец файла, под определение.

Программа должна ответить, есть ли в строке цифра. Для строки «abc1» ответ должен быть True.

Что на экране:
False

Верно. Функция посмотрела на первую букву, увидела, что это не цифра, и сразу вернула False. До единицы она не дошла. Строки с else нужно убрать, а return False поставить после цикла, на уровне слова for.

Ещё одна функция с пары лектора: она должна вернуть большее из двух чисел. Для 4 и 4 ответ — 4.

Что на экране:
None

Верно. Для равных чисел оба условия ложны: функция доходит до конца без return и возвращает None. Так и вышло у лектора на паре: вызов max_val(4, 4) ничего не показал. Вторая проверка не нужна. Если x не больше y, ответ — y, поэтому строку 4 убираем и оставляем return y, как на слайде.

Итог раздела

  • Сверху данные и функции с сигнатурами, внизу — короткая основная программа.
  • Функция может читать таблицу, созданную в программе выше.
  • Лучший вариант и его «цену» функция возвращает кортежем.

  1. Функцию определяют один раз словом def и вызывают по имени сколько угодно раз.

Проверь себя

Восемь вопросов

Сначала ответь сам — вслух или на бумаге. Потом открой ответ и честно отметь результат.

Что вернёт функция, в которой нет return?

Значение None — «ничего». Функция выполнит свои строки, дойдёт до конца и вернёт None. Если в ней был print, текст появится на экране, но программе функция ничего не отдаст.

Чем return отличается от print?

return отдаёт значение туда, откуда функцию вызвали: его можно сохранить в переменную, сравнить, передать дальше. print только показывает значение на экране. Кроме того, return сразу заканчивает функцию.

Функция f(x) состоит из одной строки print(x * 2). Что выведет программа из двух строк: y = f(5) и print(y)?

Две строки: 10 и None. Число 10 печатает сама функция во время вызова. Она ничего не возвращает, поэтому в переменной y оказывается None.

Запиши сигнатуру функции, которая получает список чисел и возвращает их среднее.

# average: list -> float. Слева от стрелки — тип параметра, справа — тип результата. Если функция для пустого списка возвращает None, об этом пишут в строке под сигнатурой.

Функция определена как ticket(name, seat, price). Что произойдёт при вызове ticket(12, "Анна", 30)? А при вызове ticket("Анна", 12)?

В первом случае ошибки не будет: аргументы попадут в параметры по порядку, и в name окажется число 12. Билет получится бессмысленным. Во втором случае программа остановится с ошибкой TypeError: параметру price не досталось значения.

Функция ищет в списке отрицательное число. Где должна стоять строка return False и почему?

После цикла, на одном уровне со словом for. Сказать «не нашли» можно, только когда проверены все элементы. Если поставить return False в else внутри цикла, функция закончится на первом же элементе.

Как вернуть из функции два значения и как принять их в программе?

Написать значения через запятую: return smallest, largest. Python соберёт из них кортеж. Принять можно распаковкой: low, high = min_max(data).

Площадь треугольника считают три функции: is_triangle, perimeter и area. Зачем три, если хватило бы одной? И что должна сделать программа с результатом area?

Каждая функция решает одну маленькую задачу: её легко написать, проверить отдельно и использовать снова. Функция area возвращает None, если треугольника нет. Поэтому программа сначала проверяет результат через is None и только потом выводит или использует его.
